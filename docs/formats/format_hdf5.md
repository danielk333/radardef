# HDF5 Format

---

The modern eiscat system outputs HDF5 files, to support this both a loader and a converter from the old file type **MatBz2** to HDF5 is available. The internal structure of the HDF5 format is documented in itself otherwise more details can be found in the converter [MatBzToHDF5](../reference/radardef/radar_stations/eiscat/converters/matbz2_to_hdf5.md)
